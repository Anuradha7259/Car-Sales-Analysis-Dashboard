# Car Sales Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing used-car sales records using Power BI. The dashboard provides insights into vehicle pricing, popular car brands and models, vehicle conditions, and sales patterns.

The objective is to transform raw sales data into meaningful insights through interactive visualizations and KPI reporting.

## Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Visualization

## Dataset Overview
- Dataset: Used Car Sales Records
- Total Records Analyzed: 119,410
- Includes vehicle details, manufacturing year, mileage, condition, estimated market value, selling price, and sale date.

## Data Cleaning & Transformation
Performed data preparation using Power Query:
- Handled missing and invalid values.
- Identified and excluded suspicious mileage and price entries from relevant calculations.
- Standardized text values and column names.
- Corrected data types.
- Cleaned and converted sale date values into Date/Time format.
- Investigated duplicate VINs and retained repeated auction transactions where appropriate.

## Key Performance Indicators (KPIs)
The dashboard includes five KPI cards:
- Total Sales Records (Cars)
- Average Selling Price
- Average Estimated Market Value
- Average Mileage
- Average Vehicle Age

## Dashboard Visualizations
The dashboard includes:
- Top 5 Brands by Sales Records
- Average Selling Price by Brand
- Average Selling Price by Manufacturing Year
- Average Selling Price by Vehicle Condition
- Average Selling Price by Vehicle Body Type
- Top 5 Car Models by Sales Records
- Sales Distribution by Top 5 Vehicle Body Types

## Interactive Filters
Users can explore the dashboard using:
- Transmission
- Vehicle Color
- State

## Key Insights
- Ford had the highest number of sales records among the displayed top five brands.
- Rolls-Royce had the highest average selling price among the selected brands.
- Average selling prices varied across manufacturing years and vehicle condition groups.
- Altima had the highest number of sales records among the displayed top five car models.
- Sedan represented the largest share among the selected top five vehicle body types.
